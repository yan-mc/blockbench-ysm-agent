## 1. 为什么要做这一轮

v5-r6 的裙 165 块中 164 块有 `rotation`，但**全部只绕 Y**（X/Z 中位 0、三轴 0），板尺寸 2.25×1.12×0.5。旋转率看似很高，实际是"竖片环/圆筒"，仍是方块堆叠感。

按 skill §3.6 对 160 个可解析参考工程的统计：

| 全部方块带旋转 | **85.4%**（118,180 / 138,400） |

| 旋转裙板中位尺寸 | **1.20 × 1.81 × 1.00** |

| 最大转角中位（p25/p75） | **32.25°**（15° / 68°） |
| 二轴 / 三轴旋转裙板 | 6,335 / **5,275** |

代表：`hi3_elysia` 内裙 126/126 全三轴；`yujin` `Skirt_Left3` 121/121 旋转；`bronya` `outskirt` 85/85 三轴；`ak_virtuosa` coat 薄板厚 0.15。

## 3. 最终结构

- 黑外层 3 层 × 16 片（板高 1.25 / 2.5 / 3.6 层级），切向 1.24–1.25×；
- 黑下摆 ruffle 30 片，切向 1.38×；
- 内层黑壳 32 片（低 tilt）堵缝；
- 饱和蓝壳 30 片连续露出约 2.05 单位，白边 0.35 单位；
- 五裙骨保留：`Skirt 12 / FrontSkirt 56 / BackSkirt 56 / LeftSkirt 29 / RightSkirt 29`；
- 倾角：min 4.61° / max 21.51° / mean 17.72°（v6.1 的 max 88.56°/mean 31.44° 太碎，已收敛）。

**审计**：裙 182/182 带旋转、**182/182 三轴（100%）**，板厚中位 0.30；总块 1117；303 动画未动；`bb_validate` 0 error（3 个已知 warning）。

## 4. 技术发现

1. **斜置薄板解决"圆筒感"**：每片用 `rotation=[tilt_x, yaw, tilt_z]`，逐圈扩径、相位错开；只绕 Y 的竖片环不算曲面。
2. **堵缝靠内壳+重叠，不是加板**：v6.1 262 片仍漏光；v6.2 减到 182 片 + 内壳 + 20–38% 切向重叠后干净。
3. **欧拉序需实测标定**：生成器按 XYZ 设计的斜板在引擎里出现板缝；射线遮挡测试与 **ZYX** 组合吻合（尚未最终定论）。批量前必须用 1 片 `[10,20,30]` 三轴板做投影标定。
4. **别过度加板**：更少、更宽、带内壳的薄板比大量碎板更干净（182 vs 262）。

## 5. 剩余差异（诚实）

1. T3 的黑摆有更明显的**两层荷叶边/peplum**；v6.2 黑裙更平顺、层次更少。
2. T3 蓝衬裙是**外张荷叶 + 细白条纹**；v6.2 是连续蓝壳 + 宽色块条纹，白边较粗。
3. T3 裙摆**前短后长**；v6.2 前后大致等长。
4. 侧面/背面裙宽比 T3 略大；腿仍是黑长袜（未动腿靴）。
5. ZYX 组合未最终定论，后续可做单板标定后彻底消缝。
