## 1. A) 角：旋转轴从 Z 改回 X（docs §3.4）

### 1.1 判读结论（docs §3.1–3.3）

- 官方立绘：角根在头顶两侧发际线，先向上/外长、再向前/下卷，尖端金环卷到脸前下方；带面有横向棱纹；3/4 视角能看到**角带绕左右方向翻转**（根部看正面、中段侧过去、尖端转回来）。
- 参考甘雨：x 2.7–6.4（外 3.7）、y 45.6–49.1、**z −4.7~+3.0（前后跨 7.7）** → 证实是"绕 X 轴、在 YZ 平面上的椭圆。
- **旧模型错误**：`rotation` 只有 `[0,0,±角度]`、z 跨度仅 0.85 → 只是"正面平面里画的 C 形"，45° 看必然是一排竖片。

### 1.2 参数（已落地）

```
每侧 1 骨 Horn_L / Horn_R（parent=Head，pivot=根部 (±1.55, 41.10, -0.20)）
P(t) = P0 + A·L·t + (0, ry·cosθ, rz·sinθ)
  A = normalize(±1, -0.02, 0.06)，L = 4.60（到 |x|≈6.1）
  θ(t) = 150° + 470°·t（≈1.3 圈）
  ry = 2.45 → 1.05，rz = 2.05 → 0.85（YZ 平面椭圆）
26 段近立方块，尺寸 1.45 → 0.62 等比，**rotation 全 0**（只靠位置排螺旋，避开欧拉序风险）
```

## 7. 剩余差距（诚实清单）

1. **角的圈数与粗细**：现在 1.3 圈、26 段近立方块拼成，正面看是"两道弹簧弧"但**段感仍可见**（近立方块的代价）；原画角更粗更整、棱纹更连续。改进方向：段尺寸加大到 1.6 起、或每段给轻微 rotation 让带面贴合（需再解决欧拉序）。
2. **角与头发的穿插**：角根 pivot 在 (±1.55, 41.10)，第一圈有一段从发帽内部穿过（被底发帽遮挡，不露破面），但**没有做"角从发间长出"的开口**；如要更自然，需要在发帽上开 2 个洞并加一圈发丝环绕。
3. **头发颜色偏亮偏蓝**：底发帽用 #d6dcf2/#b8c5e8 为主，整体比原画的浅紫灰更白；下一轮可把底发整体降一档（#b8c5e8/#93a4cf）。
4. **刘海仍有"竖条栅栏"感**：16 片前层等宽窄板 + 8 片后层宽板，虽然长短参差、有分缝，但**片与片之间是平行直条**，缺少"发流拐弯"；参考模型的做法是每缕 2–3 段折线（需要给每缕加段，工作量约 +30 块）。
5. **后长发是"直筒"**：5 束都基本垂直，缺少向内的弧度与末端外翻；束间 z 错开 0.45–0.85 已做，但侧面看仍偏平。
6. **双马尾从后脑长出、位置偏后**：pivot 在 y36 后侧，正面看不到；原画双马尾在耳后更靠前。
7. **脸仍偏小、头身比 6.94 偏 Q**（未动骨架比例）。
8. 眼睛**下眼睑只有 1 片、眼影层缺失**（参考模型有 4–5 片凹回脸内的暗片），近看下缘略硬。
