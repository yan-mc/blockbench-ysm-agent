## 二、三轮做了什么

### 第 1 轮（P0）· 头型 + 眼睛
1. 颅箱 7.55→5.95（顶 45.0→43.5）、下颌 1.67→0.79、脖子加长到 3.0 补上抬下巴后的空隙。
2. 下颌前脸 z −2.78 → −2.99（贴平），脸中部的水平台阶基本消失。
3. 眼睛从"纯贴图"改成"贴图 + 2 块/只"：
   - 眼睑板 1.42 宽 × 1.62 高 × 0.12 深（正面 z −3.11）
   - 虹膜板 1.24 × 1.28 × 0.05（z −3.16，压在眼睑板前）
   - **没有微雕**：无 0.2 厚瞳孔、无独立高光块。
4. 整个脸部区域重画（136×166 + 下颌 112×34），按世界坐标绘制，两个 UV 岛共用同一函数，接缝无色差。
5. 眼睑板四周的皮肤直接用脸函数取样 → 板子融进脸颊，不再是"贴上去的方块"。

### 第 2 轮（P1-1）· 头发
1. 拆掉 3 层平板冠 → 5 层递减圆顶（6.45→3.6 宽，顶 44.74）。
2. 删掉额前那块 6.6×0.66 的横条（就是"发箍"感的来源）。
3. 加 3 块深色发根底板（藏在刘海后面）→ 刘海缝隙由"露脸皮"变成"深色发影"，有了前后层次。
4. 15 撮刘海绕各自根部微转 ±1°（第一版用 ±2.5~3.5°，撮与撮交叉成"鸟窝"，已收回）。
5. 后发块从 2.6 高收到 1.6，配合降下来的头顶。

### 第 3 轮（P1-2 / P1-3）· 明度 + 腿 + 角
1. 贴图全局暗部重映射（0~0x4f → 0x18~0x4e，加冷色偏移 1.10 蓝 / 0.96 红）。
2. 蓝紫衬裙：亮 16% + 饱和度 +16%，下摆那圈终于读得出来。
3. 腿加粗、角放大 15%。

## 四、诚实清单：没解决的

1. **头身比变成 6.47（v8 是 4.95，目标 4.87）**。
   这是算术冲突：头压到 6.72 后，要在 43.5 高的身体上维持 4.87，头部只能是 9.2 高——也就是回到"竖长条"。
   真要做到 4.87，必须把下巴以下**整段身体缩 23%**（约 200 个方块 + 骨骼位置），那是重建不是打磨。
   本轮选择服从"头不要竖长条"这个可见问题，保留身体比例。若确实要 4.87，建议下一轮做一次整体 body 重标定。
2. **极限放大（8×）下能看出眼板是个凸起的矩形**：眼板侧面的 0.12 厚度在左右边缘形成一道暗边。正常观看距离（<2×）不可见。彻底解决要把眼做成"凹进脸里"的碗形，需要重做头部网格。
3. **侧视头发仍是一整片平板**：侧发是 0.54 厚的薄板，侧面（6.3×6.5 单位）几乎无起伏，还带一块来历不明的浅色斑（v8 遗留的 UV 采样区）。要修得给侧发加弧形排布。
4. **后发中上部有一块浅色"X"斑**：疑似后发方块共面 z-fighting 或 UV 采样到别的岛，本轮没定位到具体方块。
5. **裙子的 Tier 仍是"硬纸板"**：上下两层裙板是平面梯形，层与层之间有明显空隙，蓬松感不足（v8 遗留拓扑问题）。
6. **脸偏白偏平**：鼻子在游戏尺度基本看不见，嘴只有一点红；脸颊红晕在明亮环境下偏淡。
7. 侧发/发梢底部是一刀切的水平线，缺发梢收尖。

## 五、技术备注

- 生成器（可复现）：`build/gen_face_v9.py`（脸/眼/冠顶贴图）、`build/gen_color_v9.py`（明度重映射）、`build/gen_geom_v9.py`（腿/角几何）。
- 脸区 UV：颅北面 `[0,0] 136×166`，下颌北面 `[12,166] 112×34`，二者共用世界坐标函数 → 接缝无色差。
- 眼睛 UV 岛：眼睑 `(640,912) 96×104` / `(736,912)`，虹膜 `(832,912) 80×82` / `(912,912)`；四边小面统一采样 4×4 暗色。
- 冠顶贴图：`(128,960) 64×64`（5 条侧带 + 顶面 + 底面）。
- 所有新增方块都显式写了逐面 UV（`set_uv`），没有用自动避让，避免采样到别人家的岛。
