# 21 · 现代化建模总纲：服装 / 身体 / 头发 / 原画对照

> 本文是对 docs/19（旧、样本不足）与 docs/20（语料基线）之后的**方法论总结**。
> 分部件细节见同批产出的 `21a-衣服与裙子结构.md`、`21b-身体曲线塑造.md`、`21c-头发与面部.md`。

## 一、三个时代的画法，差一个数量级

| 时代 | 代表 | 方块 | 旋转占比 | 特征 |
|---|---|---|---|---|
| 女仆模组 | `maid/` 325 个 | 92（中位） | **0%** | 纯轴对齐盒子，脸/衣/发都是平板 |
| 女仆移植 YSM | 酒狐 `wine_fox` | 412 | 75% | 有旋转了，但仍沿用方盒造型 |
| **现代 YSM** | `ysm_decoded/` 161 个 | **742**（中位） | **85%** | 全模型分面化，薄片占比 **26–44%** |

**旋转方块占比是分水岭**：YSM 导出会把几何烘焙成顶点/面，作者必须自己预先旋转每个方块
才能做出曲面。0% → 85% 之间就是"十年前"和"现在"的差距。

> 我们之前做的 melodia：**386 块 / 512 贴图 / 裙子是圆环分层** —— 正落在「女仆移植」那一档。

## 二、服装：从「圆环蛋糕裙」到「竖片垂挂」

### 2.1 冠军案例：yujin（裙 776 块，占全模型 31%）

骨骼拓扑：

```
Skirt_Left / Skirt_Right          ← 左右
Skirt_Left1/Right1                ← 前片
Skirt_Left2/Right2                ← 侧片（各 128 块）
Skirt_Left3/Right3                ← 后片（各 121 块）
```

每根骨骼的方块特征：

| 参数 | 实测 |
|---|---|
| 单骨骼块数 | 55 / 84 / 121 / 128 |
| 旋转 | 几乎**全部**（124/128、121/121、55/55） |
| 旋转轴 | **绝大多数只在 X 轴**（俯仰） |
| 角度分布 | 2°(×40) / 45°(×16) / -48° / -45° / -42° / -15° / 15° |
| 尺寸 | x 0.05~2.3（薄） × y 0.09~8.1（高） × z 0.15~2.9 |
| origin.y 跨度 | 3.7 ~ 28.4（腰到地面） |
| 微细节片 | 0.06 ~ 0.24 厚 |

**结论：不是圆环，是几十条竖直薄片按不同俯仰角散开。**

### 2.2 渲染验证（`material/refmodels/_yujin_skirt.png`）

实际看起来是**军装风长外套的下摆**，不是裙子：

- 几十条长短不一的垂挂竖片（到膝盖 / 到小腿 / 更长）
- 片与片之间**前后重叠**，靠 **4 级灰阶**把叠层分开
- 每片末端**斜切出尖角**
- 片上有横向缝线、小方块（扣具/绑带）、细直线（用不同角度的面做出来）

### 2.3 为什么「圆环分层」过时

| | 圆环蛋糕裙（旧） | 竖片垂挂（新） |
|---|---|---|
| 几何 | 水平环，每环一圈方块 | 竖直条，每条一根 |
| 轮廓 | 阶梯锥台，明显"层" | 连续下垂，边缘参差 |
| 布料感 | 无 | 有（片各自倾斜） |
| 动态 | 整环一起摆 | 每片可独立摆 |
| 块数 | 100–150 | 300–800 |

### 2.4 可照抄的配方

```
长裙/大衣下摆：
  骨骼：左右 × 前中后 = 4~10 根（Skirt_L/R, _L1/R1, _L2/R2, _L3/R3）
  每根：50~130 块
  方块：x 0.5~1.3（薄） × y 2~8（高） × z 0.8~2.5
  旋转：只绕 X 轴，0° → 45° 递增，相邻差 3~10°
  下摆：末端斜切，补 0.1~0.24 厚薄片做蕾丝/毛边
  颜色：**至少 4 级明度**，否则叠层糊成一片
```

## 三、身体：不是"盒子拼"，是"分面化"

### 3.1 数据

| 部位 | 有该部件的模型数 | 方块数中位 | p75 | 最多 |
|---|---|---|---|---|
| 胸 | 84 | **14** | 32 | 169 |
| 腿 | 159 | **30** | 56 | 324 |
| 裙 | 73 | 40 | 82 | 776 |
| 发 | 146 | 66 | 119 | 871 |

### 3.2 冠军案例：hi3_elysia（身体部件 716 块）

```
LeftBreast   31 块，全部带旋转，尺寸 2~3 × 2~3 × 2
RightBreast  31 块，同上
ClothLeftBreast  29 块，**0.2 厚**（衣服版，盖在胸上）
LeftLeg      36 块（尺寸 [3,5,2] / [3,7,2] / [3,6,2] 变化）
LeftLowerLeg 35 块
ClothHipLeftInnerSkirt  126 块，**0.2 厚**
```

**胸 = 每侧 30 块旋转方块拼半球；腿 = 每段 35+ 块做粗细变化。**

### 3.3 视觉验证（`material/refmodels/_elysia_torso.png`）

放大看躯干，关键特征是**"分面化"**：

- 没有任何大平面——所有曲面都被拆成大量小方块，每块带微小角度差
- **靠贴图给每块不同的明暗**，制造"布褶/皮肤过渡"的错觉
- 边缘装饰（金线、镶边）是**独立的薄几何**，不是画上去的
- 小配件（扣具、流苏、腰链）用 0.2~0.5 的微几何

### 3.4 女性曲线的做法

Blockbench **不支持骨骼缩放**，所以收腰/丰胸只能靠：

1. **多个小方块 + 旋转**（主力）
2. **尺寸递进**（腰段方块从小→大→小）
3. **斜置方块**做斜肩/小腿弧
4. **衣服层单独一套**（`Cloth*` 骨骼），厚度 0.2，贴在身体外面

## 四、头发：发束链 + 极薄片

### 4.1 冠军：hi3_elysia 871 块（占全模型 33%）

```
BackLeftHair1   41 块，厚度 x 2~4，长 y 1~9
BackLeftHair2   49 块，厚度 x 2~7，长 y 4~14   ← 同名 +1/+2 是链式分段
LeftSideHair2   21 块，厚度 x 1~2，长 y 2~7
ClothHairBackLeftFlowerPart  95 块，**厚度 0.16~0.43**（花瓣/花饰）
ClothHairBackLeftLingDangPart 90 块（铃铛挂饰）
```

**发束按 `Hair1 → Hair2 → Hair3` 分段挂骨骼，末段最长最细。**
装饰单独成骨，厚度直接下到 0.16。

### 4.2 全语料分布

146 个模型有头发，中位 **66 块**、p75 119、最多 871。
意味着：**头发应该是全模型最重的部件之一**（我们的模型只有 ~80 块）。

## 五、官方原画对照：什么该强调、什么该省

以 `爱莉希雅 · 真我·人之律者` 官方立绘（`material/refmodels/_official_elysia.png`）为例。

### 5.1 必须在模型里强调的

| 元素 | 原画表现 | 建模对应 |
|---|---|---|
| **头发体量** | 占画面 40%，是最大视觉块 | 应占模型方块数 25~35%（871/2640） |
| **眼睛** | 大、带瞳色渐变、上眼睑深色 | 2×2/7 规则 + 4 层结构 |
| **胸腰胯对比** | 收腰明显，胸与胯都饱满 | 每侧 30 块旋转胸 + 腰段小方块 |
| **色块对比** | 白色上衣 × 深色下装 | 强对比，不要全同色系 |
| **腰部金饰群** | 视觉焦点 | 0.2~0.5 的微几何单独建 |
| **飘带/披风** | 大量透明流动感 | 长条分段 + 渐变贴图 |

### 5.2 可以省略/降级到贴图的

| 原画细节 | 处理 |
|---|---|
| 蕾丝花纹、刺绣 | **纯贴图**，不要建几何 |
| 半透明材质 | 用贴图透明度 + 少量几何暗示 |
| 细绑带、缝线 | 贴图上 1px 线 |
| 头发高光渐变 | 贴图 3~5 级明度阶梯 |
| 布料褶皱 | 分面化几何 + 每面不同贴图值 |
| 宝石切面 | 小块 + 高光贴图 |

### 5.3 配色处理

从官方原画到模型贴图的映射规律：

1. **主色 4~6 个**，每个主色给 **2~3 级明度** + 1 级高光
2. **同色系叠层必须拉开明度**（yujin 的 4 级灰阶就是为此）
3. 金色/宝石用**高饱和小块**点缀，面积占比 <5% 但位置在视觉焦点
4. 深色服装不要用纯黑（#000），用 #1a1a20~#35353c 的阶梯

## 六、特效层：顶级模型"震撼"的真正来源

统计 159 个现代模型（方块 ≥50）：

| 特征 | 覆盖 | 方块占比 |
|---|---|---|
| 含 `ysmGlow` 类发光部件 | **74（47%）** | — |
| 含武器几何（sword/wand/bow/trident…） | 44（28%） | — |
| 含光晕类（halo/moon/light/cross） | 21（13%） | — |
| **含任意特效类部件** | **105（66%）** | 中位 **2%**、p75 7% |
| 空骨骼（纯动画锚点） | — | 中位 **20%**、p75 25% |

**爱莉希雅是极端案例：1257 根骨骼里 557 根（44%）是空骨骼，特效方块 1951/2882 = 68%。**

它的骨骼命名词频：
```
ysmGlow(528)  SwordParticle(165)  Moon(109)  SwordLine(84)
FlowerC(81)   Icon(73)  CrossLight(55)  Glass(55)  LightHalo(50)  SwordWave(42)
```

所以它的"震撼"**不是角色本身更细，而是额外做了一整套独立的特效层**：
发光部件、剑影拖尾、粒子、月轮、光晕、玻璃碎片，每个元素挂自己的骨骼单独动画。

> 普通模型特效占比 2%、爱莉希雅 68% —— 这是「模型」和「特效演出」的区别。
> 做角色本体时按 2~7% 预留特效位；要冲击力时才堆到 30%+。

## 七、对 melodia 的现代化改造清单

| 项 | 现状（女仆移植时代） | 目标（现代） |
|---|---|---|
| 总方块 | 386 | **700–1500** |
| 旋转占比 | 部分 | **≥85%** |
| 薄片（<0.5）占比 | 少 | **≥26%** |
| 贴图 | 512 | **512–1024** |
| 眼高/脸高 | 10.6% | **28.6%** |
| 眼中心高度 | 0.57 | **0.30** |
| 面部件方块 | <10 | **≥36** |
| 头发 | ~80 | **200–870**（占比 25–35%） |
| 胸 | 无 | **每侧 25–35 块旋转** |
| 腿 | 方块盒子 | **每段 25–40 块**做粗细变化 |
| 裙 | 圆环分层 106 块 | **竖片垂挂 300–800 块**，4–10 根骨骼，X 轴俯仰 |
| 颜色 | 平涂 | **主色 2–3 级明度**，深色不用纯黑 |
