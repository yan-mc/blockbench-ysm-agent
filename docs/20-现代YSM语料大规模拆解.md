| 女仆模组 | 325 | 92 | **0%** | 128(177) / 64(71) |

**关键结论：旋转方块占比是现代 YSM 的分水岭。**

这是因为 YSM 导出会把几何"烘焙"成顶点/面，模型作者为了做出曲面必须预先旋转每一个方块。

## 二、脸型：两种做法并存，不是"都不用旋转"

### 2.1 统计（141 个可测头部）

| 做法 | 占比 |
|---|---|
| **单个大方块头** | 89 个（**63%**） |
| 多方块头 | 52 个（**37%**） |
| 头部含旋转方块 | 42 个（**30%**） |
| 面部件（eye/brow/mouth/nose/cheek…）方块数中位 | **36**（最丰富 168） |
| 全模型最薄方块厚度中位 | **0.025 单位** |

### 2.2 派别 A：单方块头 + 贴图 + 叠加小片（63%）

以 `爱莉希雅` 为例：

```
Head: 1 个方块，7.05 × 8.0 × 7.0，rotation = 0     ← 注意高度是 8 不是 7
面部相关骨骼 23 个，其中最典型：
  Head_Mouth_1  8 块  尺寸 [0.4, 0.15, 0.03]  全部带旋转
  Head_Mouth_3 17 块  尺寸 [0.4, 0.35, 0.03]  全部带旋转
```

**嘴不是画在贴图上，是用 0.03 厚的薄片一叠一叠拼出来的**，而且每片都旋转过。
这就是"贴图不够、再加一层几何"的思路——**面部细节靠的是「贴图 + 微几何叠加」**。

`doggo` 是同一派但眼睛更深：

```
Head 1 块 7×7×7
RightEyelid     3 块（2.0 × 2.02 × 2.0）  ← 眼睑是一个 2 单位深的盒子
RightEyelidBase 1 块（1.4 × 1.5 × 2.0）
RightEyesDot    1 块（0.26 × 0.25 × 1.2）
```

眼睛总深度 2+，**远凸出脸面**。

### 2.3 派别 B：旋转方块拼脸（37%，30% 头部有旋转）

`hi3_elysia`（2640 方块 / 100% 全旋转）的 `Head` 有 **50 个方块，50 个全部带旋转**：

```
o=[-0.16, 97.85, -8.17] s=[4.5,4,2] r=[-15, -5,  0]
o=[-4.43, 93.98, -9.31] s=[4.5,4,2] r=[  5,  0,  0]
o=[-0.07, 93.98, -9.31] s=[4.5,4,2] r=[  5,  0,  0]
o=[-4.34, 97.85, -8.17] s=[4.5,4,2] r=[-15,  5,  0]
o=[ 0.80, 91.97, -8.87] s=[3,2.5,2]   r=[  4, -3, 37.4]   ← 明显的斜置小片
```

**渲染出来看**：脸不是方的，是**下巴收窄、脸颊外扩的弧面**，眼睛是内嵌的杏形。
（见 `material/refmodels/_head_hi3_elysia.png`）

`bronya_reason` 介于两者之间——头 3 块，主块 6.4×6.3×6.1，另加**两块斜置的**
`[1.4, 2.8, 0.4] r=(-5, ∓39.7, ±7.8)` 修脸颊轮廓。

### 2.4 结论

> **脸方的根本原因不是"没旋转"，而是"头是 7×7×7 正方体 + 五官太小 + 没有面部件"**。
>
> - 63% 的模型头确实是单块，但它们靠**刘海压眉线 + 侧发贴颊 + 大眼 + 36 个面部件**把方脸盖住了
> - 37% 会额外用旋转小片塑形（下巴收窄、脸颊外扩），`hi3_elysia` 是极致
> - **两者都不把脸当成"一个方块"就完事** ——这才是差距

## 三、眼睛：28.6% 是跨风格的硬约定（105 个现代模型验证）

之前用酒狐算出 28.6%，担心它是女仆时代的遗留。**在 105 个现代模型上重算，数字完全一样**：

| 指标 | 中位 | p25 | p75 |
|---|---|---|---|
| **眼高 / 脸高** | **28.6%**（= 2/7） | 25.0% | 28.6% |
| **眼宽 / 脸宽** | **28.6%**（= 2/7） | 28.6% | 31.4% |
| **眼中心高度**（从脸底算，0=底 1=顶） | **0.30** | 0.30 | 0.30 |

头宽中位 **7.0**、头高中位 **7.0**——头尺寸也高度一致。

### 对照我的模型

| 模型 | 眼高/脸高 | 眼中心高度 |
|---|---|---|
| 现代语料中位 | **28.6%** | **0.30** |
| 酒狐（旧派） | 28.6% | 0.29 |
| **我的 melodia v5** | **10.6%** ❌ | **0.57** ❌ |

**我的眼睛高度只有语料的 1/2.7，位置高出近一倍。** 这是"娃娃眼/表情素"的根因，
而且是**唯一一个所有风格都一致的硬指标**。

### 眼睛的构造（现代派）

- 眼睑/眼白/虹膜/瞳孔 **≥4 层**，总深度 **2 单位以上**，凸出脸面
- 虹膜常见 `1.1~3.0` 宽，眼白更宽
- 眼睛上方必有**深色睫毛条**，再上一条**眉毛**（多为 2 块：内短外长）
- 典型尺寸：脸 7×7 → 眼睛占 2×2，双眼中缝占脸宽 ~40%

## 四、曲线：靠"极薄片链"，厚度中位 0.025

这是本轮最震撼的数字：

**全语料「最薄方块厚度」中位数 = 0.025 单位**（1/40 像素级）。

| 用途 | 做法 | 实例 |
|---|---|---|
| 嘴/表情 | 8–17 块 **0.03 厚**薄片，每片带旋转 | 爱莉希雅 `Head_Mouth_*` |
| 头发 | 厚 1.0–1.5 的片，链式微转（3–7°/片） | 通用 |
| 面部轮廓 | 4.5×4×2 的片，`-15°/5°/37°` 任意朝向拼弧面 | hi3_elysia 头 50 片 |
| 耳朵/面具 | 薄至 0.03–0.1 的片，复合欧拉角 | 酒狐 `Left_ear` |
| 缎带/飘带 | 一串扁片递增角度 | 酒狐 jk 蝴蝶结、hi3 樱枝飘带 |

**规律总结：**
1. **要平滑曲线 → 不是加大块，是把厚度压到 1 单位以下，用数量堆**
2. 每片之间 **3–7° 微转**，交叠遮盖折角
3. 极细微处（眼妆、嘴、丝带边缘）直接上 **0.03 厚**的片
4. 曲面不是算出来的，**是在视口里一片片摆出来的**（欧拉角无规律）
