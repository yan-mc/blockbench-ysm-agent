# 09 · 高质量模型结构深挖

> 对象：`材料/03-语料/` 里 4 个结构差异明显的成品模型。
> 工具：`tools/mine_models.py`；原始数据 `材料/_models_deep.json`。
> 目的：回答"边边角角和各种结构到底怎么处理"。

---

## 1. 样本与整体指标

| 模型 | 骨骼 | 方块 | 方比骨 | 深度 | 贴图 | 旋转在方块 | 旋转在骨骼 | inflate |
|---|---|---|---|---|---|---|---|---|
| `Femme Soule` | 160 | **2054** | **12.8** | 13 | 128/1024 | **1942** | 39 | 0 |
| `kelala1.1.5` | 160 | 777 | 4.9 | 13 | 256 | 650 | 42 | 0 |
| `霞沢美游` | 190 | 392 | 2.1 | 12 | 128 | 165 | 91 | **12 个 −0.01** |
| `kelala2.0` | 85 | 296 | 3.5 | 12 | 256 | 213 | 5 | 0 |
| `gura_v1` | **207** | 269 | **1.3** | 12 | 128 | **0** | **132** | 0 |

三个清晰流派：

- **雕刻派（Femme）**：2054 方块、尺寸中位 **1.06**、薄片 1319 个、方块级旋转 1942 个。
  靠海量小方块"雕"出形状。观感细腻，但几乎无法动画。
- **装饰派（kelala）**：中等方块数，旋转放在**方块**上（650 个）做斜切/弧度，骨骼主要做分组。
- **绑定派（gura）**：方块只有 269，但骨骼 207，**旋转 100% 在骨骼上，方块级旋转为 0**。
  方块轴对齐，靠骨骼旋转摆姿势。

> **选择判据**：要动画 / 要进游戏 → 绑定派；只做静态展示图 → 雕刻派。
> YSM 是**游戏内模型**，所以主流应该是绑定派，但语料中雕刻派数量不少（因为很多人只做展示）。

## 2. 边角处理：填缝（来自官方群教程）

来源：`材料/02-教程/建模/基岩版模型填缝思路.pdf`（作者 蓝玫瑰 / 02bunny）。

棱台转角处不填缝会"缺一块"。两种解法：

### 方法一：概括（优先）
避免 low-poly 思路，直接简化为**两个块重叠**，用整体旋转代替多处局部旋转，
材质靠贴图表达。原版风格就这么做。**但要避免过多阶梯**，否则反而破坏观感。

### 方法二：填缝
1. 复制朝向合适的元素；
2. 视角正对，旋转复制体直到外边缘与另一侧面平行
   （Ctrl+鼠标左键 / Ctrl+Shift+鼠标左键 可微调角度，一次抓不准就两边做完再修）；
3. **顶点捕捉（X 键）** 到下顶点，一侧即补齐；
4. 夹角另一面同理；
5. 小块修补边缘，或大块填完用橡皮擦掉多余贴图；
   想少填就把上层方块尺寸做大一点压下去；
6. **用 `inflate` 修面重叠，0.01–0.005 较合适**（太大凹凸明显，太小远处仍叠）；
7. 建贴图收尾。

> `霞沢美游` 用的是**负膨胀 −0.01**（内缩），说明 inflate 双向都用得上：
> 正值往外撑遮缝，负值往里收避穿模。

**判据**：大块结构才值得填；小结构用方法一概括过去。
"像素低模软件建模雕只会害了你"——这是原作者的原话。

## 3. 眼睛：4 层结构

`kelala2.0` 的眼部层级（YSM 标准做法）：

```
Eyes
└─ Eyelid
   ├─ LeftEyelid [1]
   │  └─ LeftEyelidBase [1]
   │     ├─ LeftEyesDot [2]
   │     │  └─ bone26 [1]
   │     └─ LeftPupil [2]
   └─ RightEyelid [1]
      └─ RightEyelidBase [1]
         ├─ RightEyesDot [2]
         └─ RightPupil [2]
   ├─ LeftEyebrow
   │  ├─ bone15 [1] / bone16 → bone24 / bone25
   └─ RightEyebrow [1] / [1]
```

**四层：眼睑 → 眼底 → 眼白点 / 瞳孔 → （高光块）**。
好处是：
- 每层单独 cube，可分别上色，贴图上能画出虹膜/高光/睫毛；
- 眨眼动画只动 `Eyelid`，不影响瞳孔；
- 左右眼球各 2 个方块（EyesDot + Pupil），不是一整块。

对比本项目 `sakiko-final`：眼睛是 `Eyelid[2×2] + EyesBase[1.4×2] + Pupil[1×1]`，
层级对，但**缺 EyesDot（眼白点）和高光层**，所以眼睛看起来"糊"。

## 4. 头发：两条路线

### 路线 A：骨骼链（`gura_v1`）
```
Head → Cap → Zuo2 → Eer(耳)
                   → bone11 → bone14
                   → bone12
                   → bone13
                   → bone15 … bone23 → bone23→bone23
```
- 207 骨骼 / 269 方块 = **1.3 方块/骨骼**，一半以上骨骼是空控制器。
- 每缕头发 = 一条**骨骼链**，可做物理摆动（配合 `parallel` 动画）。
- 代价：骨骼多、动画成本高，但**动态效果最好**。

### 路线 B：贴图分层（`kelala2.0`）
- 10 个 hair 骨骼 / 76 方块 / 占全模型 **25.7%**。
- 用较少的方块靠贴图画出层次，靠少量骨骼做整体摆动。

语料整体：**头部区域占方块 33.2%**（见 `docs/08`），头发是最大投入项。

## 5. 语义化层级（两个模型都遵守）

`kelala2.0` 的躯干分层特别值得学：

```
Root → AllBody
  ├─ DownBody [12]          臀/裙摆直接挂在 DownBody
  │   └─ LeftLeg [5] → LeftLowerLeg [2] → LeftFoot [1] → LeftSole [2]   ← 鞋底单独一组
  └─ UpBody [22]
      └─ UpperBody [31]     ← 躯干细节（外套、胸、腰）都在这里
          └─ AllHead [3] → Head [3]
```

要点：
- `DownBody` / `UpBody` 自己**带方块**（不是纯容器），承担臀/腰和大块躯干；
- `UpperBody` 是"细节层"，31 个方块，外搭、领子、胸饰全在这里；
- `LeftSole`（鞋底）单独一组——底部贴图常与鞋面不同，分开好画；
- 部件后缀语义化：`Base`/`Dot`/`Sole`/`Sock`/`Shoe`。

## 6. UV 与贴图压力

| 模型 | 贴图 | UV 面积需求 / 贴图面积 | 逐面方块 |
|---|---|---|---|
| `Femme Soule` | 128 与 1024 各一 | **159%**（超 100% → 大量 UV 复用/重叠） | 2054 |
| `霞沢美游` | 128 | **96.6%**（快撑满） | 2 |
| `kelala1.1.5` | 256 | 69.4% | 0 |
| `gura_v1` | 128 | 66.9% | 0 |
| `kelala2.0` | 256 | **15.9%**（很宽松） | 0 |

结论：
- **128×128 是"刚好够"的下限**，一旦方块数上 400，UV 就要靠重叠复用硬塞（`霞沢` 96.6%）。
- **256×256 有充足余量**（`kelala2.0` 仅用 15.9%），是性价比最高的选择。
- 512 适合雕刻派（方块多、贴图分区多）。

> 与 `docs/08` 的语料统计一致：512 占 35%、256 占 19%、128 占 21.5%。

## 7. inflate 的两种用法

| 值 | 用途 | 出现 |
|---|---|---|
| **+0.01 ~ +0.005** | 撑出一点点遮住接缝，防 z-fighting | 填缝教程推荐值 |
| **−0.01** | 向内收，避免相邻方块面重叠穿模 | `霞沢美游` 12 处 |

**规则**：只要两个面会共面或几乎共面，就动 inflate。
不要用大幅 inflate 当圆角——那是雕刻派的做法，会让方块边缘发虚。

## 8. 对本项目模型的直接结论

`sakiko-final`（56 骨 / 196 方块 / 128 贴图）对照语料：

| 项 | sakiko | 语料中位 | 差距 |
|---|---|---|---|
| 方块数 | 196 | 306 | 偏少 36% |
| 头部占比 | ~28% | 33.2% | 略低 |
| 贴图 | 128 | 512/256 主流 | **偏小一档** |
| 眼睛层级 | 3 层 | 4 层 + 眼白点 | 缺 1 层 |
| inflate | 0 | 用于填缝/避重叠 | 未用 |
| 方块级旋转 | 少 | 装饰派大量用 | 未用 |

**优先改进顺序**：① 贴图升到 256 → ② 补眼白点/高光层 → ③ 头发分骨骼链 →
④ 用 inflate 处理关节接缝 → ⑤ 方块总数补到 300 左右。
