## 0. 读之前：三个口径（否则数字会被误读）

### 0.1 坐标与世界变换
Bedrock geometry 里 `bone.pivot` 与 `cube.origin` 都是**模型空间绝对坐标**，旋转绕 `bone.pivot`，子骨骼随父链一起转。分析时按 `M = Π(T(pivot_i)·R_i·T(-pivot_i))` 累积，旋转顺序按 Blockbench 的 ZYX。
→ 所有"宽/高/深"都是**世界空间**的 AABB 尺寸，和你在 Blockbench 里看到的量一致。

### 0.2 部位怎么认（两种手段，不靠拍脑袋）
1. **名字正则**：`breast|boob|bust|oppai|胸|乳`、`leg|thigh`、`lowerleg|calf|knee`、`skirt|dress`、`cape|cloak|wing|tail`…
2. **骨架拓扑**（名字不靠谱时用）：**躯干链 = 手臂/头的祖先节点 ∩ 非头非臂**。标准骨架里它给出 `AllBody→UpBody→Upper_body`；对 `hi3_elysia` 这种自建骨架，它正确给出 `Hip→Spine→Chest→UpperChest`（这个模型一个 `UpBody` 都没有）。

### 0.3 "宽度"到底量的是什么
每个 y 切片（0.5 或 1 单位）上，把所有方块的 x 区间合并成连通段，**取包含 x=0 的那一段的宽度**。
→ 手臂/手/头发/披风/武器按名字剔除，**保留躯干+胸+胯+腿+裙**。所以本文的"宽"是**身体轮廓宽**（含贴身衣物和裙），不是"含手臂的剪影宽"。
→ 腰/胯/胸的定义：在 **腿枢轴 y → 臂枢轴 y** 之间取剖面，腰 = 中段局部最细，胯 = 腰以下最宽，胸 = 腰以上最宽。每个模型用自己的枢轴，不用统一比例，避免把小个子模型量歪。

## 1. 十条结论（先看这个）

1. **胸 = 20–70 个小块拼的球冠，不是一个方块。** 高配每模型 24–134 块（分侧后每侧 12–67），**99.6%（1529/1535）的胸块带旋转**，旋转角中位 **48°**（p25 35° / p75 69°）。球面拟合半径中位 **3.56**，残差 19% —— 是"手搓的球冠"，不是精确半球。
2. **胸有两套材质**：皮肤版厚度中位 **1.4**（高配 2.0），衣服版薄片 **0.25–0.35** → **差 4–8 倍**。`hi3_elysia` 是唯一同时给出两套的教科书：`LeftBreast` 31 块 2×2×2 + `ClothLeftBreast` 29 块 0.25 厚。
3. **收腰不靠加骨骼。** 躯干链中位只有 **2 段**（1 段 31 个、2 段 66 个、3 段 29 个），但躯干方块的**旋转占比中位 0.974**（127 个模型里 85 个 ≥0.9）。曲线是在**一根骨骼内部**用旋转小板堆出来的。
4. **只有 36% 的模型有"真收腰"**（腰比上下都窄 ≥10%），其余靠**胯宽对比**。全语料 **腰/胯 = 0.657**（p25 0.559 / p75 0.789）。
5. **语料是梨形**：**胯/胸 = 1.36**（p25 1.17 / p75 1.57），**86%** 的模型胯比胸宽。
6. **腿：中位 14 块/侧**（p25 9 / p75 26），高模 36–72 块/侧。做法是**环切**：每环 7–9 块 2 厚的板，绕 Y 约 40–45° 等分，环高 5–7，往上递减。
7. **膝最细处 = 26% 身高**，膝宽 = 腿最宽的 **72%**（p25 64% / p75 82%）→ 大腿→膝收 28%，再小腿肚鼓回去。
8. **臀：93% 的模型根本不做臀骨。** 不漏缝靠两招：裙顶比腿枢轴高 **5.9**（93% 的裙盖过胯）+ 大腿骨往上伸进胯 **1.55**（96% 的腿伸进去）。
9. **肩：A-pose 外展 18°**（p25 15° / p75 20°，125/157 落在 15–30°）；肩线 **78% 是平的甚至外侧更高**，不靠斜置方块做斜肩。**颈 98% 不做**（只有 3 个模型有带块的 Neck 骨）。
10. **手 = 每只 2 块**（p25 1 / p75 4.25），分指只有 **9/169 = 5%**，手套 4 个。

## 2. 骨架底子：你要先摆对枢轴

### 2.1 标准 YSM 骨架（160+ 模型的共同底）
```
root → whole → AllBody
   ├ DownBody → Leg → LeftLeg ──────────→ LeftLowerLeg → LeftFoot
   │                        └ RightLeg ──→ RightLowerLeg → RightFoot
   └ UpBody  ─┬ Arm → LeftArm → LeftForeArm → LeftHandLocator → (Finger*)
              │      └ RightArm → …
              ├ AllHead → Head → Hair/眼睛/嘴/…
              └ Breast            ← 胸骨多数挂在这一层（UpBody 31 / UpperBody 31 / Upper_body 12 根）
```
- 出现率：`LeftArm/RightArm` 167、`LeftLeg/RightLeg` 167、`AllHead` 164、`UpBody` 164、`DownBody` 165、`LeftForeArm` 165、`LeftFoot` 160。
- 胸骨父级分布（带块的胸系骨 207 根，取前六）：`Breast` 39、`UpBody` 31、`UpperBody` 31、`Upper_body` 12、`Breath`（拼写变体）12、`breast_armor` 7。

| `hsr_jingliu__d803a5536723` | 标准 2 段（`UpBody` 255 块 + `Upper_body` 155 块） | 单段内做收腰的样板：12.2 → 6.7 → 13.1 |

| 量 | 中位 | p25 | p75 | 说明 |
|---|---|---|---|---|

## 3. 胸（Q1）

### 3.1 语料分布
- **100 个模型定义了 `Breast` 系骨骼**（骨名家族 105 种 / 263 个骨），其中 **79 个带几何**（68 个"皮肤版"、28 个"衣服/护甲版"、17 个两者都有）。
- **57 个用单骨**（一个 `Breast` 同时管左右），**11 个用双骨**（`LeftBreast`/`RightBreast`、`Breast_Left`/`Breast_Right`…）。
- 每模型胸块数（皮肤版，含左右）：**中位 7，p25 3，p75 21**，最大 134。
- 分档（59 个"局部胸凸"模型）：

| 块数档 | 模型数 | 厚度中位 | 长度中位 | 高度中位 | 宽度中位 |
|---|---|---|---|---|---|
| 1–3 块 | 20 | 3.00 | 4.47 | 4.2 | 6.9 |
| 4–9 | 20 | 1.22 | 3.12 | 5.1 | 7.3 |
| 10–19 | 8 | 1.16 | 2.88 | 5.5 | 7.0 |
| 20–39 | 4 | 0.74 | 2.50 | 6.3 | 7.5 |
| 40+ | 7 | 0.48 | 2.02 | 10.0 | 10.1 |

> 读法：**块数越多 → 单块越薄、越短**（0.48 厚 / 2.0 长），整体越高越宽。这就是"从贴一块板"到"用薄片包一个球"的迁移。

### 3.2 尺寸与位置（按身高归一化，59 个局部胸凸模型）
| 量 | 中位 | p25 | p75 | 含义 |
|---|---|---|---|---|
| 胸高/身高 | **0.120** | 0.105 | 0.147 | 胸占身高 12% |
| 胸宽/身高 | **0.173** | 0.163 | 0.188 | |
| 胸深/身高 | **0.120** | 0.103 | 0.151 | |
| 单块最薄边 | 1.40 | 0.97 | 2.05 | 皮肤版 |
| 单块最长边 | 3.10 | 2.78 | 3.90 | |
| 位置 t（0=腿枢轴，1=臂枢轴） | **0.82** | 0.78 | 0.87 | 胸心在肩下 18% 躯干长 |

**结论：胸心高度 = 肩下 0.18 躯干长；整胸体量 = 身高 × (0.17 宽 × 0.12 高 × 0.12 深)（两侧合计；单侧各约 0.09H 宽）。**
（口径提醒：本表的"胸宽"是**胸骨包围盒的宽**，单骨模型自动含左右两侧；per-side 数据见 §3.5 与 §5 的配方。）

### 3.3 形状：半球？斜切？分层？——三个都成立，看档位
**(a) 球冠（高配的共性）**
对每侧胸块中心做最小二乘球拟合（53 侧）：

| 量 | 中位 | p25 | p75 |
|---|---|---|---|
| 拟合半径 r | **3.56** | 1.60 | 5.12 |
| 残差 RMS | 0.63 | 0.16 | 0.89 |
| RMS/r | **0.19** | 0.08 | 0.25 |

→ 是**球形**，但残差 19% 说明表面是"有棱的球"，不是数学球面。
**关键否证**：如果把每块最薄轴当作"法向"，它与径向的夹角平均 **57°**（≈随机）——即**这些块不是按球面法向精确铺的**（`hsr_jingliu` 52°、`jizi` 51–57°、`nvshi` 61°）。所以它不是"测地线穹顶"，而是**先堆成球状团块、再用乱序大角度旋转打散方块台阶**（旋转角中位 48°，不是"微调"）。

**(b) 分层（薄片派的必然结果）**
按 1 单位 y 分带数块：`jizi` 16 层、`zhe_1` 18 层、`yujin` 13 层、`bronya` 11 层、`nvshi` 11 层。
每层块数呈中间厚两端薄的钟形（`jizi`：2 0 0 1 2 0 2 7 14 15 7 3 3 0 0 1）→ **中间最鼓，上下收**，这正是球冠的横切。

**(c) 上斜切**
竖直方向的前突剖面（16 个大胸模型）：最前突在**下 1/3**（band 0 前突 3.5 → band 7 只有 2.2）。
→ 胸的**上表面是斜的**（被锁骨/领口切掉），下缘最饱满 = 水滴感。**别做成上下对称的半球。**

### 3.7 配方（可直接照抄）

**配方 B0 · 胸板（1 块，10 秒，MC 皮肤风）**
- 尺寸 `[6.5–7.1, 2.2–3.2, 2.0–3.0]`，中心 x=0，前表面比胸壁再前 **1.0–1.5**；
- 绕 X **−5°～−10°**（上缘后仰）；
- 证据：`gf_ump40` `[7.08,3.0,2.0] rot[-5,0,0]`；`ba_miyako` `[6.14,2.23,0.93] rot[-9.75,0,0]`。

**配方 B1 · 双球（2–3 块，低成本但比胸板好）**
- 每侧 1 块 `3.0–3.2` 立方，中心 x=**±1.6–2.0**，绕 Z **±7.5°**（向外张）；
- 或 3 块：两侧 `3.15×3.9×2.9`（绕 X −31.6°、Y ±5.5°）+ 中间 `1.0×3.1×2.0` 填缝；
- 证据：`dvafree` 两块 `[3.08,3,3] rot[0,0,±7.5]`、`gs_qz_yg` 三块。

**配方 B2 · 球冠（20–35 块/侧，现代高模标准）**
1. 定心：胸心 = **肩下 0.18 躯干长**，前表面 = 胸壁前 **+1.85**（p75 3.0）；
2. 体量：每侧 **宽 4.1 × 高 4.0 × 深 3.9**（≈ 身高 × 0.09 / 0.09 / 0.09；46 高的模型中位值），球半径 **3.5**；
3. 单元：**2×2×2** 的方块（`elysia` 31 块/侧，全部带旋转）；
4. 旋转：绕三轴**乱序**，总旋转角中位 **48°**（35–69° 是主区间）；不要按球面法向摆（语料里法向偏差 57°，等于没对齐）；
5. 上缘斜切：把最高 2–3 块的上表面压低 1–1.5，做出锁骨下的斜切；
6. 下缘饱满：最前突点放在**下 1/3**（band 0 前突 3.5 → 顶部 2.2）。

**配方 B3 · 薄片球冠（25–70 块/侧，极限画质）**
- 单元 **0.3–0.5 厚 × 2–3 长 × 1–2 宽**的薄板；
- 按 y 分 **7–16 层**，每层 4–15 块，中间层最多（钟形分布）；
- 每层沿球面绕 Y 排开，层与层之间的厚度/长度递减；
- 证据：`hsr_jingliu Breast` 87 块/0.35 厚、`jizi Breast` 116 块、`ruanmei Breast` 134 块/0.21 厚。

**配方 B4 · 衣服版（叠在 B2/B3 外面）**
- 复制皮肤版轮廓，**沿外法向偏移 0.2–0.4**；
- 厚度压到 **0.25**（软布）或 **1.0**（硬甲）；
- 块数保留 80–100%（`elysia` 31→29）；
- 单独一根 `Cloth*Breast` 骨，挂在胸骨或 `UpperChest` 下。

## 4. 腰 / 胯（Q2）

### 4.1 先给结论：收腰不是"多段递减"
| 项 | 中位 | p25 | p75 |
|---|---|---|---|
| 躯干链带块骨数 | **2** | 2 | 2 |
| 躯干链方块数 | 36 | 20 | 60.5 |
| **躯干方块旋转占比** | **0.974** | 0.859 | 1.0 |
| 躯干方块最薄边 | 0.97 | 0.35 | 1.49 |
| 躯干块 \|rotZ\| | 11.7° | 2.3° | 22.4° |
| 躯干块 \|rotY\| | 3.4° | 0° | 10.3° |

分段分布：**1 段 31 个 / 2 段 66 个 / 3 段 29 个 / 6 段 1 个**。
→ 骨骼层面根本没有"很多段"可用；127 个模型里 **85 个躯干旋转占比 ≥0.9**，只有 2 个模型躯干完全不带旋转。
**所以：曲线是在一根骨骼内部，用一堆带旋转的小板做出的"八边形截面"，不是靠骨骼分段的尺寸递减。**

### 4.2 唯一的多段样板（想抄可以直接抄）
`hi3_elysia__ae12017978c2`：`Hip` 19 块 → `Spine` 23 块 → `Chest` 8 块 → `UpperChest` 13 块；宽度 **20.1 → 17.1 → 13.1 → 12.6**；躯干块旋转占比 **0.986**。
它的截面做法（以 `Spine` 为例）：**前板（8–9 宽 × 6 高 × 2 厚，绕 X −17.5°）+ 左右侧板（2 宽 × 4–7 高 × 4 厚，绕 Z ±25° 外倾）+ 背板**，即一个八边形管。侧板的 `rotZ=±25°` 是"收腰"的真正来源（把侧壁往里倒）。

### 4.3 真收腰只有 36%
在 114 个可测模型里，**41 个（36%）**存在真正的局部腰（腰比上下两侧都窄 ≥10%）：
| 量 | 中位 | p25 | p75 |
|---|---|---|---|
| 收腰深度（较窄一侧 / 腰宽） | **1.27** | 1.19 | 1.48 |
| 腰的位置（0=腿枢轴，1=臂枢轴） | **0.34** | 0.26 | 0.49 |

收腰最狠：`_enderman_girl_2.0` 3.0（深 2.80）、`game_yommyko` 3.2、`jizi` 6.7、`hsr_jingliu` 6.7、`ba_toki_v1.2` 5.7、`nvshi` 7.2。

**剩下 64% 靠"胯宽"制造对比**——这是语料的主流：腰并不细，但胯/裙很宽。

### 4.4 宽比统计（114 个模型）
| 比值 | 中位 | p25 | p75 | 解读 |
|---|---|---|---|---|
| **腰 / 胯** | **0.657** | 0.559 | 0.789 | 腰只有胯宽的 66%，这是最强的曲线信号 |
| 腰 / 胸（含肩） | 1.000 | 0.825 | 1.000 | **腰并不比上胸窄**！曲线是"下宽上窄"的锥形 |
| **胯 / 胸** | **1.361** | 1.173 | 1.573 | 胯比上胸宽 36% → 梨形 |

分档：腰/胯 <0.85 的占 **82%**，<0.9 的占 89%，<1 的占 96%。
胯/胸 >1 的占 **86%**（即绝大多数模型的胯比上胸宽）。

### 4.6 配方

**配方 W1 · 两根骨版（标准 YSM 骨架，够用）**
1. `UpBody` 里做上身：胸部最宽处 = 肩枢轴间距 × 1.0（≈7.0–7.5），向下每 3–4 单位收 0.4–0.8；
2. `DownBody`/`Hip` 里做胯：宽度 = 胸宽 × **1.36**（p25 1.17 / p75 1.57）；
3. **腰点放在腿枢轴上 0.34 躯干长**处，宽度 = 胯宽 × **0.66**；
4. 侧壁用 **2 厚 × 3–4 宽**的板，绕 Z **±20–25°** 外倾（`elysia` 的 25° 是最常见值），前后板绕 X **−15°～−25°**；
5. 躯干块**全部带旋转**（哪怕只有 2–5°）——语料里 85/127 的模型躯干块旋转占比 ≥0.9。

**配方 W2 · 四段脊柱版（要极限曲线）**
- `Hip → Spine → Chest → UpperChest`，宽度 **1.0 : 0.85 : 0.65 : 0.63**；
- 每段 8–23 块，每段一圈：前板 + 后板 + 左右侧板（±25°）；
- 段间 y 重叠 2–3 单位（防止转身时露缝）。

### 5.2 构造：环切（这是语料里最统一的"曲面"手法）
把 `hi3_elysia` 的 `LeftLeg` 按 y 聚环：

| 环 | y | 块数 | 尺寸（厚×宽×高） | 绕 Y 旋转值 |
|---|---|---|---|---|
| 1 | 39.4 | **9** | 2 × 3.0–4.0 × 6 | 0, 20, 20, 38, 42, 55, 62, 84, 85 |
| 2 | 46.0 | 9 | 2 × 3.0–4.0 × 6 | 同上 |
| 3 | 51.7 | 9 | 2 × 3.0–4.0 × **7** | 同上 |
| 4 | 57.7 | 9 | 2 × 3.0–4.0 × 5 | 同上 |

`LeftLowerLeg` 7 环：y 20.7/27.5/32.9/36.2 各 **7 块 2×3×9、6、4、3**（**板高从 9 递减到 3**），y 14.1 三块、y 10.1 三块收口。
→ **同一环内绕 Y 等分（约 40–45°，记录值因方块 90° 对称折叠在 0–90°），环与环之间板高递减**，这就是"圆柱近似"。

### 5.3 从胯到踝的宽度序列（55 个 ≥12 块腿的模型）
| 位置 | 宽度中位 | 相对 |
|---|---|---|
| 大腿（15%） | 4.09 | 1.00 |
| 膝（45%） | 4.04 | **0.99** |
| 小腿肚（65%） | **4.63** | **1.13** |
| 踝（95%） | 4.60 | 1.00 |

更精细的"最细点"测量（54 个模型，按 1 单位带找 30–75% 区间的最小宽度）：
- **膝最细处 = 26% 身高**（p25 22% / p75 29%）；
- **膝宽 = 腿最宽处的 72%**（p25 64% / p75 82%）；
- 腿网格总高 = 50% 身高。

高模的分段宽度（thigh → knee → calf → ankle）：
- `hi3_elysia` 10.9 → **5.6** → 8.1 → 9.2（靴子把踝撑回去了）
- `hsr_jingliu_2` 6.0 → **3.9** → 5.7 → 5.3
- `zhe_1` 4.8 → 5.3 → **6.2** → 1.4

### 5.4 斜置方块：腿是语料里旋转率最高的部位
| 段 | 旋转块占比中位 | p25 | p75 |
|---|---|---|---|
| 大腿 | **1.00** | 0.50 | 1.00 |
| 小腿 | 0.67 | 0.00 | 0.94 |
| 脚 | 0.62 | 0.44 | 0.84 |

板厚：大腿 **1.93**、小腿 **2.25**、脚 **1.0**。
→ **大腿几乎 100% 带旋转**（因为整个大腿就是环切管），小腿有**约 1/4** 的模型保留平直的方块腿（低模，p25 = 0）。

### 5.5 配方

**配方 L1 · 低模腿（每侧 3–6 块）**
- 大腿 1 块 `[3, 5, 2]`、小腿 1 块 `[3, 6, 2]`、脚 1–2 块 `[3, 2, 4]`；
- 不做旋转，靠贴图分色（袜口/靴口）暗示膝线；
- 证据：语料里 25% 的腿属于这一档（thigh ≤2 块）。

**配方 L2 · 标准腿（每侧 10–20 块，推荐）**
1. 大腿 **3 环 × 6–8 板**，每板 `2 厚 × 3 宽 × 5–6 高`，绕 Y 每 45° 一块；
2. 小腿 **3 环**，板高从 9 → 6 → 4 递减（做小腿肚）；
3. 膝环把宽度收到大腿的 **0.6–0.65**；
4. 踝环 3 块收口（`elysia` 的做法）；
5. 脚：`[3, 2, 4]` 的鞋 + 1 块鞋跟/鞋底。

**配方 L3 · 高模腿（每侧 35–70 块）**
- 环数 4（大腿）+ 7（小腿），每环 7–9 块，板 `2 × 3–4 × 4–9`；
- 绕 Y 按 0/20/38/42/55/62/84 分布（方块 90° 对称，实际是 8–10 边形）；
- 大腿骨往上多伸 **1.5–2 单位**进胯（防漏缝）；
- 证据：`hi3_elysia` 96 块/侧、`jizi` 124 块、`zhe_1` 75 块。

- 其余模型：头直接坐在 `UpperChest`/`Upper_body` 上，靠**领口/围巾/项圈**遮住接缝。

### 7.4 配方

**配方 S1 · 肩（默认）**
- 臂枢轴 x = **±3.5**，`LeftArm` 绕 Z **−18°**（右臂 +18°）；
- 三角肌：在臂骨最上面加 1–2 块 `[2, 2.5, 2.5]` 绕 Z 再外倾 10°，把肩头做圆；
- 肩宽目标 **10.5–11.5**（= 身高 × 0.22）。

**配方 S2 · 领子（要"斜肩"感时）**
- 加一根 `Collar` 骨挂在 `UpperChest` 下，做 3–5 块 `0.3–0.8 厚`的领片，前低后高；

- 外面用领子/项圈盖住 80%。

| 项 | 手法 | 数字 |
|---|---|---|
| **胸** | 前突 + 球冠 | 47% 模型前突 >1，中位 1.85，p75 3.05 |
| **胯** | 裙/胯布外扩 | 胯/胸 1.36 |
| **腰** | 局部收 + 侧板内倒 | 真收腰 36%，腰/胯 0.66 |
| **腿** | 环切 + 高膝位 | 单侧中位 14 块，高模 96；腿占 51% |
| **头身比** | 视觉 4.5–5 头身（方块口径 ≈7.3，见 §9.1 口径说明） | 中位 4.87（视觉） |
| **腿长** | 小腿加长 | 大腿:小腿 = 1:1.6 |

### 10.3 与原画相比的三条"系统性偏移"
1. **头更大、身更短**：视觉主流 4.5–5 头身（方块口径 ≈7.3），而多数二次元原画是 6.5–7 头身 → YSM 的方块头无法做小，只能压缩身体（腿占 51% 已经是压过的结果）。
2. **胸更"集中"**：原画的胸是分布式的体积，语料把它做成**一个前突的球冠**（峰值在躯干 0.54 处），宽度只占身高 0.17 —— 视觉上更"聚"。
3. **胯靠衣服而不是解剖**：胯宽 1.36×胸宽主要由**裙子/胯布**贡献（裙块中位 39 块，`yujin` 776 块），裸胯（骨盆）通常只有 8–10 宽。

## 11. 必做清单 / 可省清单

### ✅ 必做（缺了就不像女性角色）
1. **胸**：每侧 ≥8 块、2–3 单位、全部带旋转；体量 **整胸 0.17H 宽（每侧 ~0.09H）× 0.12H 深**；前突 ≥1.5 单位；峰值在下 1/3。
2. **腰/胯对比**：胯宽 ≥ 胸宽 × 1.2；腰 ≤ 胯 × 0.8；侧板绕 Z ±20–25°。
3. **腿的环切**：大腿 ≥3 环，膝收到大腿的 0.6–0.65，小腿肚鼓回 1.4×膝宽。
4. **腿根防漏**：大腿伸进胯 1.5–2；裙/胯布盖过腿枢轴 4–8。
5. **A-pose 18°**：`LeftArm` 绕 Z −18°、`RightArm` +18°（否则肩是方的）。
6. **视觉头身比 4.5–5**（方块口径 ≈7.3，见 §9.1），腿占身高 ≥50%。

### ⭕ 可省（不影响辨识度）
1. 手指（95% 不做）
2. 单独的颈骨（98% 不做，用领子遮）
3. 臀骨（93% 不做）
4. 锁骨/肩胛（不做）
5. 衣服版胸（28/169 有；如果衣服本身贴身，直接用皮肤版轮廓 + 贴图即可）
6. 斜肩几何（78% 的模型肩线是平的）

### ⚠️ 别做（语料里没有/会翻车）
1. **别把胸做成"一个宽方块"就完事**——那是 20 年前的 MC 皮肤；语料里 1–3 块的模型只占 34%，且都是低模。
2. **别用精确球面法向铺胸片**——语料里法向偏差 57°（等于随机），精确铺反而"太硬"。
3. **别靠加骨骼段数解决腰**——中位只有 2 段；曲线在段内。
4. **别把腰做得比胸窄很多**——腰/胸中位 1.00；真正的对比在胯。
5. **别让裙顶低于腿枢轴**——93% 的裙都在上面，低了会露缝。
