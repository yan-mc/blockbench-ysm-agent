# 23 · 眼睛 / 头发 / 角的参考模型实证分析（2026-11-08）

> 目的：解决丰川祥子模型三个最大结构问题——**眼睛不像正常眼睛、头发分层导致露皮/栅栏感、角的旋转轴画错**。
> 方法：**逐个打开参考模型亲自看**，不是统计。把模型渲染图里的部件与 JSON 方块一一对应，记录每块的位置、尺寸、旋转、相对脸面的凹凸。
> 参考模型：`material/refmodels/ysm_decoded/` 下 169 个现代 YSM 工程；本轮亲自打开并逐个判读了 **doggo、zhe_2、ak_kaltsis、yujin、gs_gy_yg（甘雨）、hi3_elysia、hsr_jingliu_2、ba_alice_6.0** 等。
> 参考渲染与裁切证据：`models/togawa-sakiko/artifacts/refstudy/`（本地，不入库）；原始参考模型不入库。

---

## 0. 方法说明（为什么不能靠统计）

参考模型的**最终观感由三样东西共同决定**：贴图颜色 / 方块几何 / 层与层的深度关系。统计"每眼几块、平均尺寸"无法回答"为什么它的眼像杏仁、我们的像宝石"。
本轮做法：
1. 给参考模型造最小可开 YSM 包（main.json + texture.png + ysm.json），用 `bb_project_open` 在后台 Blockbench 打开；
2. 渲染 2400² 的 front / iso / back，再裁头、裁眼；
3. 读该模型对应骨骼的 cube 数据（origin/size/rotation/相对脸面 z 偏移）；
4. **把渲染图上看到的每一层（眼白/虹膜/眼线/下睑/眉）与数据里的方块对应起来**；
5. 多个模型互相对照，提炼成可复用的结构配方。

### 1.6 五模型共同规律（可直接照抄的配方）

1. **眼白 = 一块大平板**：2.0–2.2 宽 × 1.3–1.8 高 × 0.3–0.36 厚；**前表面几乎与脸齐平（凸 0.02~0.07）**，绝不整片凸出。
2. **虹膜/瞳孔 = 2–34 个小片叠出来**：每片厚 0.03–0.4，**整体只比眼白凸 0.03~0.15**；大量使用 **45°/90° 旋转**拼菱形、圆环、十字高光；从不做"一整块方板"。
3. **上眼睑/眼线 = 2–12 块细长斜板**：沿上睑弧线排列，rot Z −40°…+40°，**凸出 0.3–0.7（是眼睛最凸的部分）**；外眼角另有一块更大更凸的 3D 斜片。
4. **下眼睑/眼影 = 凹回脸内（−0.15~0）的暗片**。
5. **眉毛 = 2–9 块薄片**，从内到外逐块旋转+缩短，拼成弧。
6. **尺寸**：眼宽 ≈ 脸宽 28–30%（2.0–2.2 / 7），眼高 ≈ 脸高 20–26%（1.3–1.8 / 7），眼中心在脸高 30–40% 处（从脸底算）。
7. 高阶模型（甘雨）把**脸做成斜板拼面**，眼睛装在斜面上；这一步可选，先把眼睛层次做对更重要。

### 2.3 狗哥

Hair 27（底发）+ front_h1 14（刘海）+ FLongHair/LongHair 28（后长发）+ S2 60（大束/双马尾）+ armA2/B2（发束分支）。同样是"底发帽 + 独立束 + 独立分支"。

### 2.4 规律

1. **必须有底发帽**：覆盖头顶/后脑/两侧，由 **20–80 块小板**拼成（1–4 宽 × 0.5–2 高 × 0.5–1 厚）；不是 2 块大板，否则从侧面/背面必然露头皮或像盖子。
2. **前发/侧发/后发/附属物各成组**（独立 bone 或 bone 链），下缘互相叠压 1–3 单位。
3. **后发是独立大件**：30–60 块，分 3–6 束，长到腰/臀，束间错开叠压。
4. **发饰/辫子/丝带挂独立 bone**，不混进底发。
5. 每束内部：等粗多段链（每段 2–5° 微转），末 1–2 段收尖。

### 2.5 祥子现状问题

- `Hair` 只有 12 块，其中 2 块是 **7.2×0.55×7.8 / 8.2×1×8.7 的大平板**（顶盖），侧/后覆盖不足 → 45°/背面看会露头，且"头顶像盖子"。
- `front_h1` 27 刘海 + `corner_h1` 8 侧角 + `hl_side` 8 + `hl_m` 56 后发，全部是平板直接堆，束与束没有明确叠压 → **栅栏感**；`hl_m` 同时承担后发和双马尾，结构混乱。
- 没有"内层填充"防漏，没有独立"发饰"组（Ribbon 15 块是唯一装饰）。

## 3. 角：官方图 + 参考模型的旋转轴判读

### 3.1 官方立绘判读（`artifacts/refstudy/sakiko_head_horn_3x.png`、`sakiko_hornR_5x.png`）

- 角根在**头顶两侧**（发际线附近），先向**上/外**长，再向**前/下**卷，尖端（金环）卷到脸前下方。
- 角带表面有**横向棱纹**（一圈一圈，像弹簧的圈）；内侧面（朝前/朝下的一面）更亮，说明带面在卷曲中发生翻转。
- 从 3/4 视角可以看到**角绕左右方向（X 轴）在翻转**：根部看到的是角带的正面，中段逐渐侧过去，尖端又转回来——这正是螺旋绕 X 轴的表现。
- 用户判断："旋转中心是左右轴，同时像弹簧一样向两侧扩展"——与以上判读一致。

### 3.2 现有模型的错误

- `Horn_R_01/02/03` 与左角共 6 骨 50 块；所有方块 `rotation` 只有 `[0,0,±角度]`（**只绕 Z 轴**），z 范围仅 **-1.39 ~ -0.54**（0.85 厚），x 1.18–6.46，y 37.85–44.39。
- 即：现在是"**在正面平面里画的一个 C 形螺旋**"——旋转轴是前后轴（Z），不是左右轴（X）。从 45° 看就是"一排竖片"，不是弹簧。

### 3.3 参考：甘雨的角（LeftHorn/RightHorn 各 13 块）

- x 范围 **2.7–6.4**（向外 3.7）
- y 范围 **45.6–49.1**（高 3.5）
- **z 范围 -4.7 ~ +3.0（前后跨 7.7！）**
- 两个 pivot 中心：[5.5, 47.3, 1.96] 与 [3.81, 48.77, -2.04]
- 方块是 1–2.5 单位近立方大块（带 inflate 缩边），靠旋转+重叠连接。

**结论**：甘雨的角是**绕 X 轴卷、在 YZ 平面上的大椭圆**（ry≈1.75、rz≈3.85），同时 x 一路向外——这正是"以左右轴为旋转中心、像弹簧一样向两侧扩展"。Sakiko 的角应该照这个思路做，但她的角在正面看更接近圆形/椭圆（ry rz 接近），且卷数更多（约 1.2–1.4 圈）。

### 6.2 "眼角小方块勾勒眼型"的实证
