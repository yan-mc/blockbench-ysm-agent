## 1. 管道

节点签名来自 ComfyUI `/object_info` 实测：

```
LoadImage
  → SeeThrough_LoadLayerDiffModel   (SEETHROUGH_LAYERDIFF_MODEL)
  → SeeThrough_GenerateLayers       (image + layerdiff_model + seed + resolution + steps)
  → SeeThrough_LoadDepthModel       (SEETHROUGH_DEPTH_MODEL)
  → SeeThrough_GenerateDepth        (layers + depth_model + seed)
  → SeeThrough_PostProcess          (layers_depth + tblr_split + use_lama) → parts + preview
  → SeeThrough_SavePSD              (parts → 各层 PNG + layers.json)
  → SaveImage                       (preview → 可从 /history 下载)
```

8 个节点，全部用字符串 id 便于定位。

## 2. 踩到的两个坑

### 2.1 `filename_prefix` 不能带子目录

第一次跑：推理完整跑完（节点 2/5/1/3/6/4 全执行），**最后一步 SavePSD 炸**：

```
FileNotFoundError: output\seethrough/decomp_..._back hair.png
```

原因：`filename_prefix='seethrough/decomp'` → 节点拼出 `output/seethrough/...`，
但 **SavePSD 不会自动建子目录**。

修：prefix 用扁平名 `seethrough_<slug>_<时间戳>`，输出直接落 `output/`。

### 2.2 `SavePSD` 的 STRING 输出不进 `/history`

`/history/{prompt_id}` 里只有 `SaveImage` 的图片输出。`SavePSD` 返回的信息文件路径
**不在** outputs 里，所以不能靠它定位产物。

修：每次运行用一个**唯一前缀**，跑完按前缀去 ComfyUI 的 `output/` 目录 glob
`{prefix}_*_layers.json`，再从 JSON 里拿各层文件名。

## 3. 产物

### 3.1 语义分层（原始 24 层 → 插件输出 22 层）

> See-through 原始输出 **24 层**（body 13 + head 11）；插件按语义合并为 **22 层**（例如对称层合并/命名归一）。
> 层名就是部件名，每层是**原图尺寸**的独立 PNG（内容在对应 bbox 内）：

| 组 | 层名 |
|---|---|
| 头发 | `back hair`、`front hair` |
| 头饰 | `headwear` |
| 脸 | `face`、`ears-l/r` |
| 眼 | `eyebrow-l/r`、`eyelash-l/r`、`eyewhite-l/r`、`irides-l/r` |
| 五官 | `nose`、`mouth` |
| 身体 | `neck` |
| 服装 | `topwear`、`bottomwear`、`handwear`、`legwear`、`footwear` |

另有每层配套的 `*_depth.png`（深度图）。

### 3.2 `layers.json`

```jsonc
{ "prefix": "...", "timestamp": "...", "width": 832, "height": 832,
  "layers": [{ "name": "back hair", "filename": "..._back hair.png",
               "left": 320, "top": 19, "right": 506, "bottom": 308 }] }
```

`left/top/right/bottom` 是原图坐标 —— **直接可用于在 Blockbench 里定位部件比例**。

## 4. 相比 T1 的关键优势：遮挡补全

实测同一张立绘（`ref_001.png`）：

| | T1（SAM2） | T2（See-through） |
|---|---|---|
| `back hair` | ❌ 被身体/前发挡住，拿不到 | ✅ **完整重建** |
| `headwear`（发饰） | 只能看到可见部分 | ✅ **两侧都补全** |
| `face` | 只能粗略一块 | ✅ 眼/眉/鼻/嘴**分开** |
| 语义命名 | 无（区域 0/1/2） | ✅ 名字即部件 |
| 耗时 | 8 秒 | 156 秒（首次含权重下载约 20 分钟） |

`front hair` 层里脸部区域是**被挖空**的 —— 说明层级顺序是对的，这正是建模需要的遮挡关系。
