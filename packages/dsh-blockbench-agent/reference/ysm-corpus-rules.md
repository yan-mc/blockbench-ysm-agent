# YSM 现代语料实测规则（169 个解密工程）

> 数据来源：`material/refmodels/ysm_decoded/`（用 OpenYSM/YSMParser 从本机 520 个 `.ysm` 解出，
> 去重后 169 个工程；**169/169 可解析**，其中 8 个是带 `//` 注释的 JSONC，需宽松解析）。
> 旧版本基于已删除的 181 模型语料，**数据已作废**。
>
> ⚠️ **口径警告（必读）**：本文件的"头身比 4.87"是**视觉头口径**（含头发/角的包围盒）；
> 建模对齐应使用**头方块/骨骼口径 7.31**（见 §5.1）。两者不可混用、不可互相"改到达标"。
>
> 详细拆解见 `docs/20`、`docs/21`、`docs/21a/b/c`。

## 5. 比例

### 5.1 头身比有两种口径（不要混用）

| 口径 | 定义 | 值 | 用途 |
|---|---|---|---|
| **头方块/骨骼口径** | 总高 / 头骨方块高（7.0） | **7.31**（p25 6.54 / p75 9.88，n≈117–140） | **建模对齐用**；报告优先用这个 |
| 视觉头口径 | 总高 /（下巴→发顶，含发/角包围盒） | **4.87**（p25 4.49 / p75 5.29，n=122） | 只用于"看起来几头身"的审美判断 |

> 实测教训：用 4.87 当目标去改会陷入物理不可能（头压到 6.72 后要维持 4.87，头必须 9.2 变竖长条）。
> `docs/21b` 的"压到 4.5–5 头身"是**视觉口径**的表述；若按头方块口径执行，不要照它做。

## 6. 骨架共性

- 标准底：`root → whole → AllBody → {DownBody → Leg → LeftLeg → LeftLowerLeg → LeftFoot, UpBody → {Arm, AllHead → Head, Breast}}`
- **颈 98% 不做**（头直接坐 `UpperChest`）
- **臀 93% 不建**（只 6.5% 有臀骨），靠裙顶比腿枢轴高 **5.9** + 大腿骨上伸 **1.55** 藏缝
- **手每只 2 块**，分指只有 **5%**
- `LeftHandLocator`/`RightHandLocator` 常见，放在对应 Hand 组内
- **斜肩基本不做**：78% 平肩甚至外侧更高

## 8. 统计口径警告

⚠️ 分析这份语料时：

1. **`rotation` 不能无条件重放**——重放 yujin 方块旋转会把块甩到半径 30，
   重放骨骼旋转会把壳压进体内。**按尺寸 + 骨骼名分析，别用世界坐标反推造型。**
2. `ysmGlow*` 是**复制出来的自发光层**（82/169 模型有），会虚高发量/方块数
3. **3 个模型有整骨架副本**（`X` 与 `X2` 同时存在，抬高 9.6），每模型数需除 dup
4. `ClothHair*` 是**发饰**不是头发
5. 有 2 个模型不是标准尺度（`hi3_elysia` 2.9 倍、`_goblin` 0.652），
   跨模型比尺寸前要归一化（88% 的模型头就是 7.00，k=1.000）
6. **8 个模型是 JSONC**（带 `//`、`/* */`、尾逗号）：`al_agnes_0`、`ba_alice_4.0`、`ba_toki_v1.2`、
   `gi_furina`、`gi_furina_v2.0`、`gi_noelle_6.4`、`gi_noelle_6.6`、`hoshino_ai_1`；标准 `json.load` 会失败，需宽松解析
   （参考实现：`tools/extract_corpus.py`）。
7. **头身比必须注明口径**（§5.1），否则 4.87 与 7.31 会被当成矛盾。

## 9. 语料复用

```powershell
# 解码（YSMParser 在 tools/ysmparser/，整目录 gitignore）
tools\ysmparser\YSMParser.exe -i <输入.ysm目录> -o material\refmodels\ysm_decoded
# 提取结构（零件/骨骼/方块/贴图尺寸 → _cache.pkl，可再生成 inventory_ysm.json）
python tools\extract_corpus.py
# 索引
material\refmodels\inventory_ysm.json（169 条）/ inventory_parts.json（161 条历史派生）/ inventory_maid.json
```

> 打开某个语料工程：它多数是扁平布局（根目录 `main.json`+贴图），需要先补 `ysm.json` 再 `bb_project_open`
> （`dist/bb-agent-app/templates/ysm_default/ysm.json` 可参考）；标准包布局有 1 个（`爱莉希雅__1769436c7a73`）。
> 不要求逐字复刻语料（不要为指标凑块）；语料用于**看结构、量比例、找参考做法**。
